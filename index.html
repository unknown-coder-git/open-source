AES-256-GCM Encryption Tool

Browser-native · Zero dependencies · PBKDF2 100k

Algorithm: AES-256-GCM
KDF: PBKDF2-SHA256

Encrypt

Enter a password and the plaintext you want to encrypt. The output is a single Base64 string containing salt, IV, and ciphertext.

Decrypt

Paste the Base64 ciphertext produced by this tool and provide the original password used during encryption.
